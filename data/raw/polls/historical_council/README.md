# Historical Council poll comparison

`poll_responses.csv` contains six audited September 2022 Forum ward samples, one Council reading per independently recruited sample. Shares are fractions of the source's reported decided/leaning base, unnormalized. Candidate names are joined within the official year/ward contest, with the source spelling retained separately. `reading_base` is a reported table base; it is not asserted to be unweighted or an effective sample size.

`source_documents.json` records the twelve acquired physical artifacts, hashes, retrieval timestamps/URLs and full visual QA. Source bytes are retained locally under the gitignored `data/source_documents/historical_council/`; no redistribution grant was observed. `acquisition_audit.csv` preserves all twelve Council tables and explicit exclusions, including an inconsistent total, ambiguous fieldwork date and a deceased candidate whose votes were not counted. Only the primary six are eligible for the displayed comparison.

The builder joins source shares to the exact pinned Results release on every build and selects the latest eligible sample per contest within the predeclared 21–45-day horizon. Source shares remain unnormalized. The named-set vote model separately normalizes the same named candidates in each poll and official result, fits their joint composition, and propagates uncertain discrepancy. Other is never allocated. The original full-share error span remains audit metadata, not the chart interval.
